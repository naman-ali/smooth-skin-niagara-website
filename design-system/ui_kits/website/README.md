# Website UI Kit — Homepage

Recreation of the homepage header + hero, modeled directly on the client-provided reference mockup (`assets/reference-hero-section.png`). Composed from `components/core`, `components/navigation`, `components/trust` — no new primitives introduced here.

Sections below the hero (services grid, about, pricing, results, footer) were not specified in any provided source and are intentionally not built — see readme.md "Intentional additions" note.
